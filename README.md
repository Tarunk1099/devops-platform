# DevOps Platform

A production-style DevOps platform built to demonstrate practical implementation of Git, Linux, Docker, CI/CD, Infrastructure as Code, AWS, Kubernetes, monitoring, and deployment automation.

## Project Overview

DevOps Platform is a deployment-management API that acts as the application workload for an end-to-end DevOps implementation.

The application is intentionally lightweight. The primary focus of this project is the engineering and operational infrastructure built around it.
